# URL Shortener - Step 1: Base62 Math Engine

A foundational project to understand how real-world URL shorteners (like Bitly, TinyURL, and YouTube links) map database records to short, collision-free URLs.

---

## 💡 How It Works

1. In a relational database, every saved URL gets an auto-incrementing integer ID (`1`, `2`, `3`...).
2. Because sequential IDs are generated by the database, they are **100% unique** (zero collisions).
3. We convert that Base10 decimal number into a **Base62 string** using characters `0-9`, `a-z`, `A-Z` ($10 + 26 + 26 = 62$).

### Capacity of Base62:
* **1 character:** $62^1 = 62$ URLs
* **2 characters:** $62^2 = 3,844$ URLs
* **4 characters:** $62^4 = 14,776,336$ URLs
* **6 characters:** $62^6 = 56,800,235,584$ URLs (over 56 billion!)
